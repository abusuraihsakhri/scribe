What it does

The essentials for writing and reviewing Markdown, without an account or a complicated workspace.

Editor, split or preview

Switch layouts with Ctrl 1, 2 and 3. In split view you can drag the divider, and the preview updates as you type.

GitHub-flavored Markdown

Tables, task lists and strikethrough render as they do on GitHub. Code blocks get syntax highlighting and a copy button.

Tabs that keep their place

Open as many files as you like. Each tab has its own undo history, cursor and scroll position, and shows a dot when it has unsaved changes.

Command palette

Ctrl Shift P lists every command with its shortcut. Type a few letters to filter.

Find and replace

Search with match case, whole word or regular expressions, step through matches, and replace one or all.

Formatting toolbar

Headings, bold, italic, strikethrough, inline code, code blocks, links, images, quotes, lists, checklists, tables and horizontal rules, one click each.

Lists that continue themselves

Press Enter in a bullet, numbered or checklist item and the next one starts for you. Enter on an empty item ends the list. Tab and Shift Tab change the indent.

Your files stay as they were

Scribe remembers whether a file uses Windows (CRLF) or Unix (LF) line endings and saves it the same way, so git doesn't see changes you didn't make.

Safer Markdown preview

Rendered Markdown is sanitized, and local image paths are checked before loading. As with any file, use care with untrusted content and external links.

Opens from your file manager

Double-click a .md, .markdown, .mdown or .mkd file, or drag files onto the window. A second file opens in the running window instead of a new one.

Light, dark or system theme

Follows your system setting by default. Zoom the whole window with Ctrl = and Ctrl -, or go fullscreen with F11.

Settings you'd expect

Font, font size, tab size, word wrap, line numbers, current-line highlight, optional autosave, a list of recent files, and export to a standalone HTML page.

From download to first draft

No registration, workspace setup, or cloud account required.

New in 0.1.3

  • Undo no longer moves text from one tab into another.
  • Files with Windows line endings no longer show as modified when you haven't changed them, and are saved with their original line endings.
  • Autosave no longer opens a Save As dialog for new, unsaved documents.

Full changelog

Local files, local control

Scribe works with Markdown documents on your device rather than requiring a hosted account. Files are opened and saved locally. Markdown that references images on external websites may request those images from the referenced host. The project site itself requests public release information from GitHub for download links.
