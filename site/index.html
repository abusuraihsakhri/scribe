Scribe / Markdown editor for desktop

Write Markdown.
See the result.

A small, native editor with a live preview, multiple tabs, and practical editing tools. Open and save ordinary Markdown files on your computer.

Download Scribe View on GitHub
Free and open source · Windows, macOS, Linux

What it does

Editing, previewing, and organizing Markdown files without a cloud workspace.

Live preview

Switch between editor, preview, and a resizable split view. GitHub-flavored Markdown supports tables, tasks, and code highlighting.

Multiple documents

Keep files open in separate tabs, each with its own cursor position, undo history, and unsaved-change indicator.

Find and replace

Search by text or regular expression with whole-word and case-sensitive options. Replace one match or all matches.

Keyboard-first editing

Use the command palette, formatting toolbar, and automatic continuation for lists and checkboxes.

Local file handling

Open files from your file manager, preserve LF/CRLF line endings, and export a document as standalone HTML.

Adjustable workspace

Light or dark appearance, type settings, word wrap, line numbers, recent files, and optional autosave.

Getting started

No registration, workspace setup, or cloud account required.

Install the desktop app

Choose the package that matches your operating system below.

Open a Markdown file

Create a new note or open an existing .md document with the file picker or drag and drop.

Write, preview, save

Switch between editor, split, and preview layouts. Your edits save to the local file you choose.

Read the changelog

Local files, local control

Scribe works with Markdown documents on your device rather than requiring a hosted account. Files are opened and saved locally. Markdown that references images on external websites may request those images from the referenced host. The project site itself requests public release information from GitHub for download links.

Scribe is built with Tauri 2, React and CodeMirror 6. Source · Report an issue
